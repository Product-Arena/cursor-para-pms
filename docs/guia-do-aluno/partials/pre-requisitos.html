ANTES DE COMEÇAR

Pré-requisitos

Faça isso antes do dia do curso. Cada item tem um motivo — sem ele, alguma parte do dia não funciona. Separe tempo pra concluir tudo com calma.

1
Criar conta e instalar o Cursor desktop conta, download e instalação no seu computador
Obrigatório
  1. Acesse cursor.com e clique em Sign in para criar sua conta (e-mail ou Google/GitHub).
  2. Na mesma página, clique em Download e instale o app desktop (macOS ou Windows). O curso usa o Cursor instalado, não apenas o navegador.
  3. Abra o app, faça login e confirme que está na tela inicial.

💡 Plano Pro (pago): é fortemente recomendado para acompanhar o ritmo do curso e concluir todos os exercícios propostos. O plano gratuito pode limitar uso e recursos em partes do dia.

Antes do curso, valide com a empresa se você pode instalar apps e usar IA no computador corporativo. Se houver bloqueios de rede ou política, use um computador pessoal para não travar exercícios ao vivo.

2
Workspace modelo "cursor-workspace" área de trabalho organizada para o dia do curso
Obrigatório

Estruturamos uma área de trabalho modelo com as pastas do dia e a pasta .cursor/ (rules, commands, templates). Siga o roteiro abaixo e marque cada etapa — o progresso fica salvo neste navegador.

0/4
Passo 1 2 min

Baixar o workspace modelo

Baixe o arquivo cursor-workspace.zip e salve em um local de fácil acesso (por exemplo, Downloads).

Baixar cursor-workspace.zip
Passo 2 2 min

Descompactar o zip

Extraia o arquivo até virar uma pasta (ex.: cursor-workspace). O Cursor abre pastas, não arquivos .zip.

Recomendação: mova a pasta para Documentos (ou outro local fixo), não só em Downloads — evita perder o material depois do curso.

Passo 3 5 min

Abrir a pasta no Cursor (File → Open Folder…)

No Cursor, use o menu File → Open Folder… (Abrir pasta) e selecione a pasta extraída cursor-workspace — a mesma sequência da apresentação do curso.

  1. Com o Cursor aberto, clique em File na barra superior.
  2. Escolha Open Folder… (Abrir pasta).
  3. Navegue até cursor-workspace e confirme com Open.
Passo 4 1 min

Validar no explorador de arquivos

No painel à esquerda, confirme que a raiz do workspace mostra repos/ e .cursor/. A partir daqui, todos os exercícios usam esta mesma pasta aberta.

CRITÉRIO DE PRONTO

Workspace cursor-workspace aberto no Cursor; na raiz você vê repos/ e .cursor/ sem precisar abrir outra pasta.

3
Conta no GitHub repositório do curso e versionamento
Obrigatório

O que é: pense no GitHub como um Google Drive para código: um lugar na nuvem com arquivos e pastas que você pode baixar para o seu computador e manter sincronizados. No curso, você clona o repositório oficial, versiona entregas e publica protótipos. Além do material da aula, o GitHub ajuda a encontrar ferramentas complementares (skills, templates, MCPs) que o instrutor indica ao longo do dia.

Como criar a conta:

  1. Acesse github.com e clique em Sign up.
  2. Cadastre-se com e-mail (pessoal ou corporativo, se a empresa permitir) e confirme o acesso.
  3. Escolha o plano Free — é suficiente para o curso.

SSH (opcional, depois): a maior parte dos exercícios funciona com HTTPS, sem configurar nada extra. Se quiser clonar sem senha repetida, siga o SSH no GitHub (no Apêndice) quando tiver um intervalo.

4
Criar conta e projeto no Linear issues, épicos e integração via MCP
Obrigatório

O que é: Linear é uma ferramenta de gestão de trabalho para times de produto e engenharia — parecida com o Jira, porém mais rápida e enxuta na interface. No curso, você transforma a PRD em projeto, épicos e tarefas pelo agente, usando o MCP do Linear, sem copiar escopo manualmente entre ferramentas.

Como criar conta e projeto:

  1. Acesse linear.app e clique em Sign up (ou aceite o convite do workspace, se a empresa já usar Linear).
  2. Crie um workspace (ou entre no workspace indicado pelo instrutor).
  3. Crie um projeto para o curso (ex.: Cursor na prática — Arena Cash) — é onde ficarão issues e épicos do exercício.

Jira vs Linear: se você já usa Jira, pense em Linear como o mesmo papel (backlog, status, prioridade), com fluxo mais leve para o dia a dia de produto. No curso, o importante é ter um projeto seu para o agente criar e organizar tarefas.

5
Conta na Vercel publicar protótipos e apps com link público
Opcional

O que é: Vercel é uma plataforma de hospedagem na nuvem para sites e apps web. Ela pega o que você construiu no Cursor e coloca no ar com um link público — ideal para compartilhar protótipos, dashboards e MVPs com o time ou stakeholders sem depender só do seu computador.

Como usamos no curso: no Bloco 7, depois do localhost, você versiona no GitHub e pode publicar com GitHub Pages. A Vercel entra como caminho opcional para deploy com preview automático, domínio amigável e builds um pouco mais robustos — útil quando quiser mostrar o protótipo fora da sala.

Como criar a conta:

  1. Acesse vercel.com e clique em Sign Up.
  2. Entre com a mesma conta do GitHub (recomendado) para conectar repositórios com um clique.
  3. Complete o onboarding — o plano gratuito cobre os exercícios de demonstração do curso.

Não é obrigatório ter Vercel pronta antes da aula. Se faltar tempo, acompanhe a demo do instrutor e configure depois para republicar seu protótipo.
