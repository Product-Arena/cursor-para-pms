4. Branches

ComandoFunçãoUso
git branchLista branches.Ver linhas de trabalho.

Consultas rápidas:

  • Histórico conciso: git log --oneline -10
  • Desfazer mudança não commitada: git checkout -- arquivo.md
  • Diferenças totais: git diff
  • Por arquivo: git diff arquivo.md

SSH no GitHub

A chave SSH identifica seu computador no GitHub. Depois de configurada, comandos como git clone e git push funcionam sem pedir senha toda vez.

1. Gerar a chave (terminal)

No terminal integrado do Cursor (ou Terminal do macOS), rode:

ssh-keygen -t ed25519 -C "seu-email@exemplo.com"

Pressione Enter para aceitar o caminho padrão (~/.ssh/id_ed25519). Defina uma senha (passphrase) ou deixe em branco — em branco é mais simples para o curso.

2. Iniciar o agente e registrar a chave

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

3. Copiar a chave pública

macOS:

pbcopy < ~/.ssh/id_ed25519.pub

Windows (PowerShell):

Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | Set-Clipboard

O conteúdo copiado começa com ssh-ed25519 e termina com seu e-mail.

4. Cadastrar no GitHub

  1. Abra github.com/settings/keys.
  2. Clique em New SSH key.
  3. Título sugerido: Cursor — notebook pessoal (ou o nome da máquina).
  4. Cole a chave pública e salve.

5. Testar a conexão

ssh -T git@github.com

Na primeira vez, digite yes se perguntar sobre fingerprint. Mensagem de sucesso típica: Hi username! You've successfully authenticated…

Dica: para clonar o repositório do curso com SSH, use o URL no formato git@github.com:Product-Arena/cursor-para-pms.git (botão Code → SSH no GitHub).
